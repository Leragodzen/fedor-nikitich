# Сайт «Фёдор Никитич»

Статический сайт кафе-лавки-цеха в Тольятти. Чистый HTML/CSS/JS, без сборки — можно открыть любой файл прямо в браузере и залить на любой хостинг как есть.

## Визуальная система

**Идея.** Сайт построен как печатный прайс мясной лавки: у всего есть имя, вес и цена. Это буквальное прочтение их собственной фразы «честный, натуральный продукт».

**Ритм день–ночь.** Тёмные секции чередуются со светлыми. Тёмное — мясо, лавка, вечер. Светлое — завтраки, выпечка, хлеб. Так выпечка не тонет в темноте, а мясо не выглядит бледно.

**Сигнатурный элемент** — карточка логотипа на первом экране: кремовая бумага в тёмном кирпичном зале, надпись вдавливается как настоящий блинт.

### Цвета

| Токен | Значение | Откуда |
|---|---|---|
| `--ink` | `#17120E` | тёплый почти-чёрный, буквы блинта |
| `--soot` | `#241C16` | фон тёмных секций |
| `--paper` | `#F0EADC` | бумага логотипа |
| `--paper-2` | `#E1D6C0` | вторая плоскость, плашки |
| `--ochre` | `#B9822F` | фартук шефа — единственный акцент |
| `--brick` | `#7C4531` | обожжённый кирпич |

Синий из печатного меню намеренно не используется — он случайный, из шаблона.

### Шрифты

- **Oswald** — заголовки и названия блюд. Плотный конденсированный гротеск, подобран под логотип.
- **Literata** — весь текст. Тёплая книжная антиква.
- **IBM Plex Mono** — цены, вес, подписи. Даёт ощущение весов и ценника.

Все три с кириллицей, подключены с Google Fonts.

## Как править

### Поменять цену
Найти строку в нужной странице и заменить число:
```html
<li class="price__row">
  <span class="price__name"><span>Свиные рёбра</span></span>
  <span class="price__val">850 ₽<i class="price__w">500 г</i></span>
</li>
```
`price__w` (вес) можно убрать целиком, если он не нужен.

### Добавить пояснение под позицией
```html
<p class="price__note">Грудинка на кости, запечённая в смокере.</p>
```
Кладётся внутрь `<li>`, после цены.

### Заменить плашку на фото
Сейчас там, где фото ещё нет, стоит намеренная плашка с поросёнком и подписью «фото готовится». Чтобы поставить настоящее фото, весь блок `<div class="ph">…</div>` заменяется на:
```html
<img src="../assets/img/имя-файла.jpg" alt="Что на фото" loading="lazy">
```
Плашки стоят в трёх местах: сет мясника (главная), красная икра (лавка), коптильня (цех).

### Поменять режим работы
Часы указаны в двух местах, оба надо синхронизировать:
1. Таблицы `<ul class="hours">` в `index.html` и `contacts/index.html`
2. Массив `SCHEDULE` в `assets/js/main.js` — из него считается строка «сейчас открыто / откроется в…»

### Поменять телефон
Поиск по `79198135806` и `+7 919 813-58-06` во всех файлах.
