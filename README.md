# Фёдор Никитич — кафе · лавка · цех

Сайт кафе и гастрономической лавки в Тольятти, ул. Юбилейная, 85Б.

Чистый HTML, CSS и JavaScript. Ни сборки, ни зависимостей, ни фреймворков —
файлы можно открыть двойным щелчком и они будут работать.

---

## Структура

```
index.html          главная
menu/               меню кафе
lavka/              витрина навынос, торты на заказ
tseh/               производство, шеф, история
contacts/           контакты, часы, карта, вопросы и ответы
404.html            страница ненайденного адреса

assets/css/main.css  вся вёрстка
assets/css/fonts.css подключение шрифтов
assets/fonts/        Oswald, Literata, IBM Plex Mono — лежат у нас,
                     чтобы не ходить на серверы Google
assets/img/          картинки: у каждой три размера в WebP и запасной JPEG
assets/js/main.js    поведение: меню, ленты, просмотр фото, бронь,
                     спецпредложение, часы работы

tools/trace-pig.py   обводчик логотипа из растра в вектор
sitemap.xml          карта сайта
robots.txt
site.webmanifest     иконка и цвет при добавлении на домашний экран
```

Исходные материалы (оригиналы фото, макеты логотипа, скриншоты) лежат
в папке `фото/` и намеренно не отслеживаются гитом — они весят под двести
мегабайт и на сайт не идут. На страницы попадают только обработанные копии
в `assets/img`.

## Как посмотреть локально

```bash
python3 -m http.server 8000
```

Дальше открыть http://localhost:8000

Просто открыть `index.html` двойным щелчком тоже можно, но тогда не
заработает карта Яндекса и часть путей между страницами.

## Как выложить на GitHub Pages

1. Создать репозиторий на GitHub.
2. Привязать и отправить:

```bash
git remote add origin https://github.com/ПОЛЬЗОВАТЕЛЬ/РЕПОЗИТОРИЙ.git
git push -u origin main
```

3. В настройках репозитория → Pages → Source выбрать ветку `main`, папку `/ (root)`.

**Важно.** Сейчас сайт рассчитан на собственный домен, поэтому в `404.html`
и `site.webmanifest` пути начинаются с косой черты. Если публиковать
по адресу вида `пользователь.github.io/репозиторий/`, к этим путям нужно
добавить название репозитория, иначе стили на странице 404 и иконка
приложения не найдутся. На собственном домене менять ничего не надо.

## Как редактировать

**Цены и позиции меню** — прямо в `menu/index.html` и `lavka/index.html`.
Каждая строка выглядит так:

```html
<li class="price__row">
  <span class="price__name"><span>Название</span></span>
  <span class="shot-slot"></span>
  <span class="price__val">850 ₽<i class="price__w">500 г</i></span>
</li>
```

`shot-slot` — место под кнопку с фотографией. Если фото нет, оставить пустым:
колонка всё равно держит ширину, и цены остаются на одной линии.

**Часы работы** задаются в одном месте — массив `SCHEDULE` в `assets/js/main.js`.
Оттуда же считается строка «сейчас открыто до 21:00» и подсветка сегодняшнего
дня в расписании. Если график поменяется, править только там и в текстах
на страницах.

**Новая фотография.** Положить оригинал в `фото/`, затем сделать три размера:

```bash
python3 - <<'PY'
from PIL import Image
im = Image.open("фото/ИМЯ.jpg").convert("RGB")
for w in (480, 800, 1200):
    r = im if im.width <= w else im.resize((w, round(im.height*w/im.width)), Image.LANCZOS)
    r.save(f"assets/img/слаг-{w}.webp", "WEBP", quality=78, method=6)
    if w == 800:
        r.save("assets/img/слаг-800.jpg", "JPEG", quality=76, optimize=True, progressive=True)
PY
```

И вставить на страницу через `<picture>`, как сделано у остальных.

**Логотип.** Знак лежит один раз в каждом документе как `<symbol id="pig-mark">`,
остальные места ссылаются через `<use href="#pig-mark">`. Если заказчик пришлёт
вектор от дизайнера — заменить содержимое символа, всё остальное подхватится.
Пока знак обведён с растрового макета скриптом `tools/trace-pig.py`.

## Что уже сделано по технике

- Картинки в WebP, по три размера, с `srcset` — телефон качает лёгкий вариант
- У всех картинок проставлены размеры, вёрстка не скачет при загрузке
- Шрифты свои, с `preload` для основных начертаний
- Микроразметка: заведение с адресом, часами и рейтингом 5,0, меню с ценами,
  хлебные крошки, вопросы и ответы
- Картинка для мессенджеров — ссылка приходит карточкой, а не голым текстом
- Первый экран весит около 370 КБ
- Проверено: нет горизонтальной прокрутки на ширинах от 320 до 1440,
  нет битых ссылок и якорей, консоль чистая, работает с клавиатуры
- Учитывается системная настройка «уменьшить движение»
